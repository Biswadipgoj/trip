## Findings and fixes
1. **Build warning (edge runtime).** Root cause: `import { SignJWT, jwtVerify } from 'jose'` pulled JWE/deflate code into the middleware bundle. Fix: narrow imports `jose/jwt/sign`, `jose/jwt/verify`. Evidence: clean build before = 1 `CompressionStream` warning, after = 0; middleware size unchanged (39.3 kB).
2. **E2E auth suite existed only outside the repo.** Fix: `e2e/auth/auth.e2e.mjs` + `e2e/run-auth-e2e.sh`, run with `npm run test:e2e:auth` (PostgreSQL + PostgREST 12 + all migrations + `next start` + Chromium).
3. **Runner defect found while verifying fix 2.** A second run failed (`getByText('Goa Beach Week')` timeout). Root cause: cleanup killed the `npx` wrapper but not the `next-server` child, so the old server kept port 3100 and answered with the previous run's keys. Fix: services start under `setsid` and are killed by process group; the runner refuses to start if ports 3001/3100/54321 are busy. Evidence: two consecutive runs 29/29 each, 0 leftover processes, 0 leftover databases; with port 3100 occupied the runner exits 1 with a clear message.
